# Software decoding baseline first, followed by prioritized VideoDecoder evaluation

The Switch 2 port establishes software decoding on FFmpeg 7.1 and mpv 0.36.0 (`hwdec=no`) as its known-good compatibility baseline and recovery path so the first usable beta is never delayed by unproven runtime assumptions. Immediately after G2 establishes that baseline and its frame-time benchmarks, native libounce VideoDecoder hardware decoding is pursued as a high-priority performance track on an isolated branch. Zero-copy GPU import is an optimization goal rather than a hard prerequisite: a bounded-copy or GPU/EGL/Vulkan surface-import path may merge via G3 when real-console measurements demonstrate meaningful playback stability, CPU, power, or frame-pacing gains at sustainable maintenance cost, while retaining software decoding as an automatic fallback.
